Bloc 02 / Exercice 01

Calculer une variation

Question : Quel est le taux de variation des ventes entre mars et avril ? Montrez le calcul.

Python · sandbox-notebook
print((15000 / 9000 - 1) * 100)

Résultat et explication

Les ventes augmentent d’environ 66,67 % entre mars et avril.

Bloc 02 / Exercice 05

Comparer deux calculs de marge

Question : Pour le semestre, que donnent le ratio des sommes et la moyenne des taux mensuels ? Lequel mesure la marge globale sur le chiffre d’affaires ?

Python · sandbox-notebook
print(round(df["profit"].sum() / df["ventes"].sum() * 100, 2))
print(round(df["marge_pct"].mean(), 2))

Résultat et explication

Le ratio des sommes est d’environ 22,80 % ; la moyenne simple des taux vaut 22,50 %. Le ratio des sommes mesure la marge globale sur CA.
