Bloc 02 / Exercice 05

Le taux depuis janvier

Question : Calculez profit cumulé / ventes cumulées × 100, puis tracez cette série. Comparez son dernier point à la moyenne des taux mensuels. Justifiez la formule retenue pour la marge globale.

Python · sandbox-notebook
df["marge_cumulee_pct"] = df["profit"].cumsum() / df["ventes"].cumsum() * 100
moyenne_taux = df["marge_pct"].mean()
print("Ratio cumulé final :", round(df["marge_cumulee_pct"].iloc[-1], 2))
print("Moyenne des taux mensuels :", round(moyenne_taux, 2))
fig, ax = plt.subplots(figsize=(8, 4), layout="constrained")
ax.plot(mois, df["marge_cumulee_pct"], marker="o", color="#275c47")
ax.set_title("Marge sur CA cumulée depuis janvier")
ax.set_ylabel("Profit cumulé / ventes cumulées (%)")
ax.set_ylim(0, 30)
fig.savefig("/workspace/resultats/02_marge_cumulee.png", dpi=140, bbox_inches="tight")
plt.show()

Résultat et explication

Le ratio cumulé final vaut environ 22,80 %, contre 22,50 % pour la moyenne simple des taux. Les mois n’ont pas le même chiffre d’affaires. Pour la marge globale sur CA, on divise les sommes, pas la somme des pourcentages.

À faire verbaliser : Dernier ratio ≈ 22,80 % ; moyenne des taux = 22,50 %.
